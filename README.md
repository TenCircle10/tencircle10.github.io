# TenCircle10 的个人主页

*A personal academic homepage with Chinese notes on mathematical analysis.*

在线访问：**<https://tencircle10.github.io/>**

这是 [TenCircle10](https://github.com/TenCircle10) 的个人主页与笔记库，
主要放中文数学笔记、随笔，以及一点关于我的信息。

## 站点内容

- **主页** —— 关于我、研究兴趣、新闻、留言板
- **笔记** —— 数学分析相关的中文笔记，包含公式推导、图表与定理证明；主页列出公开的部分
- **每日一言 / 深浅色切换** —— 侧边栏每天换一句话，配色可跟随系统或手动切换

## 关于这个仓库

这里是站点的源码仓库，基于 Jekyll 与 GitHub Pages，主题衍生自
[minimal-light](https://github.com/yaoyao-liu/minimal-light)。笔记
内容以中文为主。

构建方式、发布流程、脚本与前端实现等维护细节都在
[`TECH_GUIDE.md`](TECH_GUIDE.md) 里。仓库中另外三个 `README_*.md` 是上游主题自带的
多语言模板说明，与本站内容无关，仅作存档保留。
