  CSS 里元素锚在文档 `(0,0)`（`left/top: 0 !important`），并加
  `transition: none !important` —— 两个球原本带 transform 过渡，不禁掉会
  把逐帧写入拖成「追不上滚动」的滞后抖动。检测阶段仍读一次
  `getBoundingClientRect()`，但 `broken=true` 后 `check()` 直接返回。
- `_layouts/note.html`：`<body>` 开头加 `window.siteScrollBehavior()`，
  减少动效返回 `instant`；返回顶部与目录跟随两处 `scrollTo` 统一接入。
- Callout **从 clip-path 改回 grid**（用户否决了 clip-path 的「内容瞬间
  让位」）：`grid-template-rows: 0fr → 1fr`，首次点击惰性包一层
  `.callout-grid`。**details 自身不能当 grid 容器**——Chrome 131+ 把非
  summary 子节点收进 `::details-content` 伪元素，跨内核直接子元素不一致。
  内层必须 `min-height:0 + overflow:hidden`，否则 auto 最小尺寸顶住内容，
  `0fr` 压不下去。中间态读 computed `grid-template-rows`：Chrome 返回 px
  （除以起手量一次的 `fullPx` 换算回 fr），部分内核保留 fr，两种都兼容。
  `CSS.supports('grid-template-rows','0fr')` 为假 / 无 WAAPI / 减少动效
  → 直接切换，宁可无动画也不跳。
- 时长与曲线：`0.3s → 0.25s`（含 `--circle-transition`）、`0.45s/0.5s → 0.2s`；
  三个 CSS 各自定义 `:root { --ease-out: cubic-bezier(0.23, 1, 0.32, 1) }`
  ——**非 `auto_dark_mode` 分支只加载 `publications-no-dark-mode.css`，
  不加载 `publications.css`**，所以那个文件必须自带变量，否则
  `var(--ease-out)` 未定义会让整条 transition 失效。loader 的 `0.5s`
  循环动画与 `0.3s` 错峰延迟按用户决策保留原样。
- `TECH_GUIDE.md` 同步修正两条已证伪的描述（`dataset.animating` 状态锁、
