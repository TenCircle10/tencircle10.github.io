## 修复 `\lbrace` 黏连字母导致公式报红 + 外来文本孤儿公式兜底

### 现象
网页端数学分析笔记多处 `\lbrace` 变红色源码、整条公式不渲染。用户最初怀疑是"外来 OCR 文本漏写 `$` 包裹的裸 `\lbrace`/`\begin`"。

### 真正根因
- 上一版（commit `cad0b88`）把 `\{` / `\}` 转成 `\lbrace` / `\rbrace`。`\lbrace` 是多字母命令，当 `\{` 紧跟字母时会黏成非法命令，例如 `\{a_1` -> `\lbracea_1` -> LaTeX 读成未定义的 `\lbracea` -> MathJax 报红、整条公式失败。
- 数学分析笔记近 20 处、线性代数若干处中招（如 `若无限集 A... A = \lbracea_1...`）。矩阵块本身 `#117-126` 一直被 `$$` 正确包裹、`\\` 也翻倍了，能渲染；页面"崩"是被满屏的 `\lbracea` 错误拖垮的观感。
- 用户猜想的"裸 `\lbrace` 没加 `$`"在当前 origin 里并不存在（grep 证实所有 `\begin`/`\{` 都在 `$`/`$$` 内）。

### 修复（sync_notes.py）
1. `\{` -> `\lbrace{}`、`\}` -> `\rbrace{}`：空分组 `{}` 不可见，彻底杜绝与后续字母黏连。
2. 边界守卫规则：`(?<!\\)\\(lbrace|rbrace)(?=[A-Za-z0-9])` -> `\lbrace{}`/`\rbrace{}`，兜底源文件里直接写 `\lbrace`/`\rbrace`（外来文本）紧跟字母/数字的情形。
3. 新增 `wrap_orphan_math`：把未被 `$`/`$$`/`\[`/`\]`/`\(`/`\)` 包裹的 `\begin{...}...\end{...}` 自动包成 `$$...$$`（三行块写法），应对 OCR/AI 漏写定界符。已包裹的环境通过"收集已定界区间并跳过重叠"来避免重复包裹。
   - 代码块安全：管线顺序是 `protect_code_blocks`（第 123 行，1078 行调用）先于 `protect_math`（1080 行），代码块已被抽成占位符，`wrap_orphan_math` 不会误伤代码块里的 `\begin`。

### 验证
- 单测通过：`\{a_1`->`\lbrace{}a_1`；字面 `\lbracea_1`->`\lbrace{}a_1`；矩阵 `\\` 翻倍仍在；裸 `\begin{matrix}` 被包成 `$$`；已包裹环境被跳过。
- 全量重跑：notes 仅 6 个含 `\lbrace` 的文件变动（数学分析 50 行、线性代数 6 行等），全是 `\lbrace{}` 修复；无新增 `$$` 块、矩阵 `&`/`\\` 完好、slugs 不变。
- grep 确认全 notes 无残留 `\lbrace[a-zA-Z0-9]` / `\rbrace[a-zA-Z0-9]`。

## X5 内核悬浮球修复（提交 35658e5）
- **用户真机定位**：安卓手机 QQ 内置浏览器（X5/XWeb 内核）里 `position:fixed` 滚动时降级成 absolute，悬浮球被冲走。
- **删除** `assets/js/scale.fix.js`（主题遗留 hack，touchstart 时改 viewport 为 minimum-scale=0.25），连带 note.html / homepage.html 的 script 标签、html_source_file 里的副本与引用。
- **CSS 加固**：notes.css 顶部给两个悬浮球加 `will-change: transform` + `backface-visibility: hidden` + `touch-action: manipulation`；把 `translateY` 动画改写成 `translate3d` 以强制 3D 合成层且不丢动画。
- **技术要点（重要）**：Blink 会把 `translate3d(0,0,0)` 在 computed style 里**扁平化成 2D matrix**（m43=0），真正建立合成层的是 `will-change: transform`。两个信号都要保留（老 Blink 靠 translate3d，新 Blink 靠 will-change）。
- **自愈兜底**：新增 `_includes/fixed-fallback.html` —— 滚动时检测按钮视口坐标漂移，确认 fixed 失效后切 `position:absolute` + 按视口换算 top/left 钉回视口。正常设备检测不到失效，零介入。
- 测试经验：puppeteer 的 `addStyleTag/addScriptTag({content})` **不能直接喂含 `<script>` 标签的整段 HTML**，会被当 JS 解析报语法错；要用正则只取 `<script>...</script>` 内的纯 JS 再 `page.evaluate()`。

### 排查方法（可复用）
- 没有 Jekyll/本地构建，改用「真实浏览器 + 线上页面」做真机验证：
  - `npm i puppeteer-core` + 本机 Edge（`C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`）走 CDP；

  - `elementFromPoint` 命中测试比截图更能说明「按钮真的在最上层可点」。
- 结论：两个按钮 `.back-to-top` / `.toc-mobile-btn` **本来就带 `position: fixed`**（bottom 20px / 80px，right 20px，已上下错开），且都是 `body` 的直接子元素；扫描全部被笔记页加载的 CSS 后确认**祖先链上没有任何 transform/filter/perspective/will-change/contain/overflow**（仓库里所有 transform 都在按钮自身、抽屉 `.toc-sidebar`、主题开关内部和装饰元素上）。Chromium 与 WebKit 双引擎、真实滚动手势下实测两球均精确钉在视口右下角 —— **该症状无法复现**。

### 实际改动（按「永久防线 + 显式钉死」加固）
1. `notes.css` / `publications.css` 顶部：`html, body { transform/filter/perspective: none !important; will-change: auto !important }` —— 杜绝日后 html/body 成为 fixed 的包含块。

3. 抽屉 `.toc-sidebar` 的 z-index 1000 -> 10001，展开时仍盖住悬浮球。

## 笔记分仓：隐藏笔记不再出现在主页（commit 65e46b1）

### 目标
缓解主页笔记列表拥挤。**不是密码保护**：hidden 仓的笔记只是不出现在主页列表，URL 仍可直接访问。

### 结构
- `origin/public/` → front matter `public: true` → 出现在主页列表
- `origin/hidden/` → front matter `public: false` → 不出现在主页，URL 仍可访问
- `origin/` 根目录下散落的 .md（历史遗留）→ 按 public 处理（向后兼容）

### 关键设计（改这类东西最容易踩的坑）
1. **输出路径必须基于「仓内相对路径」**：`origin/public/数学分析笔记.md` → `notes/shu-xue-fen-xi-bi-ji.md`、permalink 仍是 `/notes/shu-xue-fen-xi-bi-ji/`。若直接用 `path.relative_to(src)`，parent 会变成 `public/`，permalink 变成 `/notes/public/<slug>/` —— **所有旧链接一次性全断**。分仓后 notes/ 的 diff 只有新增 `public:` 一行，permalink 与正文零改动。
2. **双链映射必须全仓共享**：`build_slug_map(sources)` 吃的 `sources` 来自 `src.rglob("*.md")`（本来就是递归的），public+hidden 混在一起，所以跨仓 `[[双链]]` 照常解析。
3. **`public` 写真正的 YAML 布尔**（`true`/`false`），不是字符串 —— 否则 Liquid 的 `page.public == true` 判不出来。Jekyll 的 `page.public` 走的是 front matter 回退机制（和 `page.title`/`page.slug` 同一条路），`public` 不是 PageDrop 的保留方法名，不会冲突。
4. **fail-safe 方向**：缺 `public` 字段 → `page.public == true` 为 false → **默认隐藏**而非默认公开。宁可少显示也不泄露。
5. **仓归属是权威来源**：源笔记自己手写的 `public:` 会被 `apply_public()` 覆盖，避免手滑写错把私密笔记挂到主页。
6. **gitignore 技巧**：根 `.gitignore` 用 `origin/*` + `!origin/.gitignore`（不是 `origin/`），才能让 `origin/.gitignore` 本身入库、锚定忽略规则；`origin/.gitignore` 再忽略 `public/` 与 `hidden/`。`git add -n .` 干跑确认只有 `origin/.gitignore` 会入库，源文件零泄漏。
7. `deploy.ps1` 无路径假设（只调 `python sync_notes.py`），无需改动即兼容。
